# Implementar una feature del club

El procedimiento fijo del proyecto para implementar una feature. Síguelo entero y en orden.

1. Lee su spec en `docs/specs/` entera, incluidos los no-objetivos.
2. Implementa lo que pide la spec y nada más.
3. Añade tests que cubran cada criterio de aceptación.
4. Si cambia la API, actualiza su referencia en el `README.md`.
5. Pasa `npm run check` y no lo des por terminado si falla.

Cuando termines, resume en pocas líneas qué has cambiado y si `npm run check` pasa.
